# darcio-veiculos-pro
Sistema web responsivo para catálogo e gerenciamento de estoque de veículos, desenvolvido com HTML, CSS e JavaScript. Possui área pública para clientes visualizarem carros disponíveis e painel administrativo com login para cadastrar, editar, remover veículos e acompanhar estatísticas da loja.

# Dário Veículos - Sistema Web

Sistema web responsivo para loja de veículos com catálogo público, página de detalhes, contato via WhatsApp e painel administrativo para controle de estoque.

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Catálogo de veículos
- Página de detalhes do veículo
- Contato direto pelo WhatsApp
- Login administrativo
- Cadastro, edição e remoção de veículos
- Dashboard com estatísticas
